# 30 - Glossary

| Term | Definition |
|---|---|
| Celo | A public blockchain network designed for fast, low-cost, mobile-first payments, including stablecoins. |
| CeloHT | FreClean's Web3 infrastructure and payment partner, handling integration between FreClean's checkout and the Celo network. |
| Stablecoin | A digital asset designed to hold a steady value, typically pegged to a currency like the US dollar. |
| Valora | A mobile wallet built for the Celo network. |
| PaymentIntent | A request to pay, created before any money or asset has moved. |
| Payment | The tracked record of a payment through its lifecycle (requested → pending → detected → verified → confirmed, or a terminal failure). |
| Supported Assets Registry | FreClean's list of Celo assets verified and enabled for payment - empty until an asset is actually verified. |
| RBAC | Role-Based Access Control - restricting actions based on a user's assigned role. |
| SDS | Safety Data Sheet - the standard document describing a product's hazards, handling, and safety information. |
| Lifecycle status (product) | One of: development, prototype, available, discontinued, planned. |
| DEMO data | Data explicitly marked as fictional, used to make a system runnable without real customer data. |
| RWA | "Real-World Asset" - a category of Web3 projects tying blockchain functionality to a physical-world asset or business. |
