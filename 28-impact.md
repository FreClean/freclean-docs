# 28 — Impact

## Framework

| Metric | Source once real data exists |
|---|---|
| People trained | `freclean-entrepreneurship` training records |
| Entrepreneurs supported | `freclean-api` `/api/entrepreneurs` |
| Small businesses launched | Entrepreneur status transitions to `active` |
| Jobs created | Staff records, `freclean-api` `/api/staff` |
| Cleaning professionals trained | Staff onboarding records |
| Products distributed | `freclean-api` `/api/orders` |
| Digital payments enabled | `freclean-api` `/api/payments`, filtered by method |
| Businesses supported through growth stages | `freclean-entrepreneurship`'s growth framework tracking |

## Publication policy

No number in this section is populated until it is real and verifiable from the systems listed above. This whitepaper will be updated with actual figures as FreClean's operating history accumulates — not with projections presented as results.
